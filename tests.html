Before each release, this page builds a small synthetic register in which everything that must never publish carries the marker NEVERLEAVES: restricted and embargoed evidence, withheld sightings, the investigation log, source identities, withheld places, a held-back entry, and a struck line. It then runs the public clone and every exporter, with downloads intercepted, and proves the marker appears in no output. It never reads or writes this browser's autosave, and nothing is downloaded or sent anywhere.
